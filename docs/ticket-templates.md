# Ticket Templates (copy/paste)

Mantenerlos cortos y accionables. Si el ticket no se puede terminar en 1-2 dias, probablemente es Epic o hay que partirlo.

## Task (contenido)
Titulo: [CONTENT] ...

Entregable:
- Formato exacto (ej: tabla / markdown / JSON / planilla)

Checklist:
- [ ] Pregunta
- [ ] Alternativas (A-D/E)
- [ ] Respuesta correcta
- [ ] Habilidad/tag
- [ ] Dificultad
- [ ] Explicacion (plantilla)
- [ ] "Por que no" distractores (1 linea c/u)
- [ ] Fuente (si existe)
